# Начало работы

## Установка приложения

Приложение работает на смартфонах под управлением Android 8.0 и новее.

- Откройте магазин приложений (RuStore или Google Play).
- Найдите по названию: **Мониторинг дорожной инфраструктуры**.
- Нажмите **Установить** и дождитесь окончания загрузки.

> **Регистрация не нужна.** Аккаунт создаётся автоматически, когда вы отправляете первую заявку, — отдельно заводить учётную запись не требуется.

## Первый запуск

При первом запуске приложение попросит два разрешения. Их нужно подтвердить, чтобы подача заявки занимала минимум времени:

- **Доступ к геолокации** — чтобы автоматически определить место дефекта;
- **Доступ к камере и галерее** — чтобы приложить фотографии к заявке.

Разрешения можно изменить в любой момент в настройках смартфона.
